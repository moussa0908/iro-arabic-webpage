# 아랍어 사이트 구조 설계도와 운영 가이드

## 1. 전체 구조
```
/                          시안 비교 페이지 (한국어, 내부용, 검색 제외)
├─ ar/                     ★ C안 = 실제 운영용 아랍어 사이트
│  ├─ face-lifting/        شدّ الوجه                     리프팅 (집중 분야 1)
│  ├─ fat-repositioning/   إعادة توزيع الدهون            눈밑 지방재배치 + 얼굴 지방이식 (집중 분야 2)
│  ├─ facial-surgery/      تجديد العين والجبهة           상안검·눈썹하거상·이마거상 (집중 분야 3)
│  ├─ other-procedures/    إجراءات أخرى                  지방흡입·가슴·비수술 (#body #breast #non-surgical)
│  ├─ doctor/              الطبيبة                       원장 소개
│  ├─ journey/             رحلتكم العلاجية               치료 여정, 서울 체류, 기도·할랄 정보
│  ├─ faq/                 الأسئلة الشائعة               15문항, 4개 주제
│  ├─ consultation/        طلب استشارة                   상담폼
│  └─ privacy/             سياسة الخصوصية                개인정보 처리방침 (초안)
├─ ar-signature/           A안 (에디토리얼, 아이보리·골드), 단일 페이지
├─ ar-journey/             B안 (치료 여정, 딥그린), 단일 페이지
├─ archive/v1-initial/     A·B 초기 시안 원본 (복구용)
├─ assets/                 공통 설정·스크립트·이미지
├─ src/ar/                 C안 페이지 원고 (여기서 수정)
├─ tools/                  빌드 스크립트, 상담폼 Apps Script
├─ docs/                   이 문서들
├─ sitemap.xml, robots.txt, llms.txt
```

## 2. 홈(C안) 섹션 순서와 의도
| 순서 | 섹션 | 걸프 환자가 확인하고 싶은 것 |
|---|---|---|
| 1 | 히어로: 여성 원장 사진, "المعيار أنتم(기준은 당신)" | 누가 수술하나, 여성 의사인가 |
| 2 | 시술명 흐름 띠 | 무엇을 하는 병원인가 |
| 3 | 집중 분야 3개 + 기타 시술 3개 | 내가 원하는 시술이 있나 (선호·강점 순서로 배치) |
| 4 | 치료 여정 6단계 (가로 스크롤 고정 모션) | 한국에 가기 전에 무엇을 하나 |
| 5 | 원장 소개 | 자격과 경력 |
| 6 | 케어: 여성 원장·코디, 아랍어 통역, 사생활, WhatsApp | 말이 통하나, 사생활은 지켜지나 |
| 7 | 서울 체류 정보: 위치, 시차, 호텔, 기도·할랄 | 며칠, 어디서 지내나 |
| 8 | 자주 묻는 질문 5개 | 남은 의문 |
| 9 | 상담폼 | 전환 |
| 10 | 위치·진료시간 | |
| 11 | WhatsApp 마무리 배너 | 전환 |

**전환 동선:** 헤더 WhatsApp 버튼 → 모바일 하단 고정바(WhatsApp/상담신청) → 각 시술 페이지 상단·사이드 박스 → 상담폼 → 마무리 배너.

## 3. 시술 배치 근거
- **강점 3개를 맨 앞에:** 리프팅 → 지방재배치 → 눈·이마. 걸프 지역은 안티에이징 얼굴 시술 수요가 높아서 강점과 겹칩니다.
- **지방흡입·가슴:** 걸프 수요가 높지만 강점은 아니어서 "기타 시술"로 한 단계 낮췄습니다.
- **쌍꺼풀:** 걸프 환자는 대부분 원래 쌍꺼풀이 있어 수요가 낮습니다. 목록에서 뺐습니다. 노화로 처진 눈꺼풀(상안검)은 수요가 있어서 "눈·이마"에 넣고, 페이지에 "새 쌍꺼풀 라인을 만드는 수술이 아님"을 명시했습니다.
- **코성형:** 걸프 수요는 크지만 원장이 실제 시행하는지 확인되지 않아 넣지 않았습니다. 시행한다면 `src/ar/`에 페이지 하나만 추가하면 됩니다.

## 4. 수정하는 방법
1. 아랍어 원고는 `src/ar/*.html`에서 고칩니다 (맨 위 `<!--meta ... -->`가 제목·설명·검색 정보).
2. 터미널에서 `python3 tools/build.py`를 실행하면 `ar/` 아래 실제 페이지, `sitemap.xml`, `robots.txt`가 다시 만들어집니다.
3. 메뉴·푸터·스키마(구조화 데이터)는 `tools/build.py` 한 곳에서 관리합니다.

## 5. `assets/config.js` 설정값
| 값 | 의미 |
|---|---|
| `DRAFT` | `true`면 모든 페이지에 (콘텐츠 초안) 배지가 붙습니다 |
| `GA4_ID` | Google Analytics 4 측정 ID (`G-...`) |
| `CLARITY_ID` | Microsoft Clarity ID (히트맵·세션 녹화, 무료) |
| `FORM_ENDPOINT` | 상담폼 저장 주소 → `docs/상담폼-연동-가이드.md` |
| `CLINICS` | 병원별 WhatsApp 번호 |
| `ROUTES` | 시술별로 다른 병원·담당자 번호로 보내는 규칙 |

## 6. WhatsApp 다병원 확장 구조
- 모든 WhatsApp 버튼은 `data-wa="시술코드"` 속성만 가지고 있고, 번호는 `config.js`에서 결정됩니다.
- 순서: `ROUTES[시술]` → 페이지의 `data-clinic` → `DEFAULT_CLINIC`
- 첫 메시지에 **요청코드**가 자동으로 들어갑니다. 예: `رمز الطلب: IRO-LIFT-AR` = 이로 / 리프팅 / 아랍어 페이지. 상담 담당자가 어느 병원, 어느 시술 페이지에서 온 문의인지 바로 압니다.
- 병원을 추가할 때:
  ```js
  CLINICS: {
    iro: { code: 'IRO', name: '...', wa: '8210....' },
    abc: { code: 'ABC', name: 'عيادة ...', wa: '8210....' }   // 추가
  },
  ROUTES: { breast: 'abc' }   // 가슴 문의만 ABC 병원 번호로
  ```
- 새 병원 전용 페이지는 `src/ar/`에 원고를 만들고 `<body data-clinic="abc">`가 되도록 빌드 스크립트에 병원값을 넘기면 됩니다. 하나의 통합 WhatsApp 번호로 받은 뒤 요청코드로 병원에 배분하는 방식도 같은 구조로 됩니다(`wa`에 같은 번호, `code`만 다르게).

## 7. 분석 도구
`GA4_ID`를 넣으면 아래 이벤트가 자동으로 기록됩니다.

| 이벤트 | 언제 | 같이 남는 값 |
|---|---|---|
| `whatsapp_click` | WhatsApp 버튼 클릭 | procedure, clinic, placement(헤더/하단바/본문 등) |
| `form_start` | 상담폼 첫 입력 | |
| `generate_lead` | 상담폼 제출 | procedure, clinic, country, stored |

- GA4에서 `generate_lead`, `whatsapp_click`을 **주요 이벤트(전환)**로 지정하세요.
- 광고나 SNS 링크에 `?utm_source=instagram&utm_campaign=lifting_oct` 같은 꼬리표를 붙이면, 상담폼 시트에도 유입 경로가 함께 저장됩니다.

## 8. 검색·AI 노출(GEO) 장치
- 시술 페이지마다 **H1 바로 아래 2~3문장 직답** → ChatGPT, Gemini, Perplexity가 인용하기 쉬운 형식
- 표(체류일·회복), 체크리스트, FAQ 형식
- JSON-LD 구조화 데이터: `MedicalClinic`, `Physician`, `MedicalWebPage`, `MedicalProcedure`, `FAQPage`, `BreadcrumbList`
- `llms.txt`: AI가 사이트를 요약할 때 읽는 안내 파일
- `robots.txt`: GPTBot, ClaudeBot, PerplexityBot, Google-Extended 허용
- 페이지별 고유 title, description, canonical, hreflang, Open Graph
- 아랍어 이미지 alt, 영문 슬러그 URL

**현재는 모든 페이지에 `noindex`가 걸려 있습니다.** 원어민 검수와 의료광고 확인 전의 초안이 검색에 노출되면 안 되기 때문입니다. 공개 시 `tools/build.py`의 `INDEXABLE = True`로 바꾸고 다시 빌드하세요.

공개 뒤 할 일:
1. 자체 도메인 연결 (`robots.txt`는 도메인 최상위에서만 동작) → `tools/build.py`의 `SITE`를 새 주소로 바꾸고 다시 빌드
2. Google Search Console, Bing Webmaster Tools에 `sitemap.xml` 제출
3. 구글 비즈니스 프로필에 아랍어 소개 추가
4. 아랍어·영어 핵심 질문 10개를 AI 검색에 직접 물어 인용 여부 기록 (예: "أفضل عيادة لشد الوجه في سيول", "how long to stay in Seoul after facelift")

# 상담폼 연동 가이드

## 지금 상태
상담폼은 A·B·C 시안과 `/ar/consultation/` 모두 같은 항목, 같은 처리 코드(`assets/site.js`)를 씁니다.

| `assets/config.js` 설정 | 제출하면 일어나는 일 |
|---|---|
| `FORM_ENDPOINT` 비어 있음, WhatsApp 번호 없음 (현재) | "시험판이라 아직 연결되지 않았다"는 안내만 나옵니다. 저장되지 않습니다. |
| WhatsApp 번호만 설정 | 환자 정보가 미리 채워진 WhatsApp 대화창이 열립니다. 환자가 **전송**을 눌러야 병원에 도착하고, 시트에는 남지 않습니다. |
| `FORM_ENDPOINT`만 설정 | 구글 시트에 저장되고 담당자에게 알림이 갑니다. 환자에게는 "WhatsApp으로 연락드리겠습니다"라는 안내가 나옵니다. |
| **둘 다 설정 (권장)** | 시트에 저장되고 알림이 간 뒤, 환자 화면에 "WhatsApp으로 대화 이어가기" 버튼이 나옵니다. 환자가 WhatsApp에서 전송하지 않고 떠나도 연락처가 남습니다. |

## 저장과 알림 구조
```
환자 폼 제출
  ├─ 구글 시트 '상담요청' 탭에 한 줄 추가 (이름·국가·WhatsApp·관심 시술·방문 예정월·요청코드·유입 경로)
  ├─ 담당자 이메일 알림 (메일 안에 https://wa.me/환자번호 링크가 있어 바로 답장 가능)
  ├─ (선택) 텔레그램 / 슬랙 즉시 알림
  └─ GA4 이벤트 generate_lead 기록 (어느 시술 페이지, 어느 국가에서 왔는지)
```
- 휴대폰 알림: 구글 시트 앱에서 알림을 켜거나 텔레그램 알림을 쓰면 즉시 받을 수 있습니다.
- 카카오톡 알림톡은 사업자 채널과 유료 발송 대행사 계약이 필요해서 이번 구성에서는 뺐습니다. 필요하면 Apps Script에서 대행사 API를 호출하는 방식으로 추가할 수 있습니다.
- 사진은 폼으로 받지 않습니다(민감정보). 동의를 받은 뒤 WhatsApp으로 받도록 안내 문구를 넣어 두었습니다.

## 설치 (약 10분)
1. 구글 드라이브에서 새 스프레드시트를 만듭니다 (예: `IRO 아랍어 상담요청`).
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. `tools/consult-form-apps-script.gs` 내용을 통째로 붙여넣고, 맨 위 `NOTIFY_EMAILS`에 알림 받을 주소를 넣습니다.
4. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
5. 권한 승인 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
6. `assets/config.js`의 `FORM_ENDPOINT: ''` 따옴표 안에 붙여넣습니다.
7. 사이트에서 시험 제출을 해 보고, 시트에 한 줄이 추가되는지와 메일이 오는지 확인합니다.

> Apps Script 코드를 수정한 뒤에는 **배포 관리 → 편집 → 새 버전**으로 다시 배포해야 반영됩니다. URL은 그대로 유지됩니다.

## 스팸 방지와 보안
- 숨은 입력칸(honeypot)이 있어 단순 봇 제출은 버려집니다.
- 시트에 저장할 때 `= + - @`로 시작하는 값은 수식으로 실행되지 않게 처리합니다.
- 시트 공유 범위는 담당자로만 제한하세요. 개인정보 처리방침(`/ar/privacy/`)의 보관 기간(최대 1년)에 맞춰 오래된 행을 정리해야 합니다.

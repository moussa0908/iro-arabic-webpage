# 의료광고 검수표 (보수적 기준)

기준: 의료법 제56조(의료광고 금지 사항)와 같은 법 시행령 제23조를 보수적으로 해석했습니다. 해외(GCC) 환자를 대상으로 한 외국어 페이지도 국내 의료기관의 광고이므로 같은 기준을 적용했습니다.
UAE·사우디 보건당국의 광고 승인 제도는 현지에서 광고를 집행할 때(현지 SNS 광고 등) 따로 확인이 필요합니다.

> 이 문서는 법률 자문이 아닙니다. 공개 전에 대한의사협회 의료광고심의위원회 심의 대상 여부를 확인하고, 필요하면 심의를 받으세요.

## 1. 이번에 삭제하거나 고친 표현

| 항목 | 이전 (A·B 초기 시안) | 조치 | 근거 |
|---|---|---|---|
| 수술 전후 사진 | A: 전후 비교 슬라이더 / B: 전후 갤러리, "환자 셀카" 탭, 메뉴·하단바 링크 | **전부 삭제** | 전후 사진은 오인 소지가 있어 심의 대상이고, 보수적으로는 게재하지 않음 |
| 환자 후기·치료 경험담 | "실제 환자의 실제 결과" 문구 | 삭제 | 치료 경험담 광고 금지 |
| 효과 단정·지속 보장 | A 메인 문구 "جمالٌ يدوم نفعُه(효과가 오래가는 아름다움)", "نتائج طبيعية تدوم(오래가는 자연스러운 결과)" | "المعيار أنتم(기준은 당신)", "얼굴 균형을 고려한 설계"로 교체 | 효과를 보장하거나 단정하는 표현 |
| 최상급 표현 | "الخيار الأمثل(최적의 선택)", "الإجراء المميز(대표 시술)" | "알맞은 선택", "병원 집중 분야"로 교체 | 최상급·비교 표현 |
| 과장 효과 | B 슬라이드 "ملامح أكثر تحديدًا(더 또렷한 윤곽)" | "리프팅은 얼굴 전체 평가에서 시작합니다"로 교체 | 결과를 약속하는 표현 |
| 해시태그 | "#자연스러운_결과" 등 | 삭제 | 결과 암시 |
| 줄기세포 | A·B "줄기세포 재생 치료" | **삭제** | 줄기세포 관련 표현은 규제가 엄격하고 효능 표현 위험이 큼 |
| 상표명 | 울쎄라, 써마지, 온다, 보톡스 | 일반명으로 교체 (집속 초음파, 고주파, 보툴리눔 톡신 주사) | 특정 기기·제품 광고로 보일 소지, 아랍어 전용 원칙 |
| 통역 상시 제공 | "전문 의료 통역사가 모든 단계에 동행" | "요청 시 아랍어 통역을 연결" | 실제 운영과 다른 표현 방지 |
| 쌍꺼풀·눈매교정·눈재수술 | A·B 마지막 카테고리 | **삭제** | 걸프 환자 수요가 낮고, 집중 분야가 아님 |
| 입원 | 언급 없음 | "입원실 없음, 호텔 체류" 명시 | 사실과 다른 기대를 막기 위함 |
| 할랄·기도실 | 언급 없음 | "병원에는 없음, 이태원 서울중앙성원·할랄 식당 안내" | 사실대로 안내 |

## 2. 모든 시술 페이지에 넣은 문구
- 부작용 안내: 붓기, 멍, 비대칭, 흉터, 드문 합병증
- "결과와 회복 기간은 개인마다 다르며, 어떤 의료 행위도 특정 결과를 보장할 수 없습니다"
- 가격은 표시하지 않음 ("사진 검토 후 안내") → 할인·이벤트 가격 광고 위험 없음
- "무료 상담" 같은 유인성 표현 사용 안 함 (환자 유인 금지 조항 고려)

## 3. 원장 확인이 필요한 항목 (`data-verify`)
화면 왼쪽의 **(콘텐츠 초안)** 배지를 누르면 아래 항목이 빨간 점선으로 표시됩니다.

| 페이지 | 확인할 내용 |
|---|---|
| 리프팅 | 시술별 권장 체류일(딥플레인 10~14일, 미니 7~10일, 실 3~5일, 장비 1~2일), 실밥 제거 시점 |
| 지방재배치 | 결막 절개·피부 절개 두 방식 모두 시행하는지, 체류 5~7일, 실밥 제거 5~7일 |
| 눈·이마 | 상안검·눈썹하거상·이마거상 체류일(5~7일 / 5~7일 / 7~10일) |
| 코성형 | 체류 7~10일, 부목·실밥 제거 5~7일, 지지 재료(비중격·귀연골)만 적었음. 늑연골·보형물 사용 여부 확인 |
| 기타 시술 | 지방흡입 체류 5~7일, 가슴 7~10일 |
| 여정 | 보호자 1명 상담 동석 가능 여부 |
| 개인정보·사진 | 상담 데이터 보관 1년, 사진 비공개 원칙이 실제 운영과 맞는지 |

## 4. 마취 관련 (중요)
마취과 전문의가 없는 1인 병원이므로 **"전신마취", "마취 전문의 상주" 같은 표현은 넣지 않았습니다.** 마취 방법은 "상담 시 원장이 설명"으로만 적었습니다.
딥플레인 리프팅, 이마거상, 코성형, 가슴수술은 일반적으로 깊은 진정이나 전신마취가 필요한 경우가 많습니다. 이 시술들을 실제로 어떤 마취로 시행하는지 원장 확인 후, 시행하지 않는 시술은 목록에서 빼야 합니다.
